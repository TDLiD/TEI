DATABASE BACKUP / RESTORE

Export / Backup
  • • Downloads the entire database as a .json file to your device.
  • • Use this to create a manual backup before making major changes.
  • • Admin password verification is required to proceed.
Import / Restore
  • • Restores the database from a previously exported .json backup file.
  • • WARNING: This will completely overwrite all current data and cannot be undone.
  • • Admin password verification is required to proceed.

* WARNING: Restoring will overwrite all current database records. Admin password required.
